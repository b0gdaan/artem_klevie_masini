# Решения

## D1. Язык: Python 3.11

Нужны краулинг и разбор HTML, API Search Console и PageSpeed Insights, статистика и рисунки для текста.
Python закрывает всё одним стеком (requests, BeautifulSoup, pandas, numpy, matplotlib); у Google есть
официальный `google-api-python-client`. JavaScript/Node удобен для Lighthouse и axe-core, но статистика и
отчёты в нём хуже; R силён в статистике, но слабее для краулинга и сложнее в поддержке для автора.
Версия 3.11 выбрана как стабильная и совпадающая с CI (3.14 на машине тоже есть, но lock сделан на 3.11).

## D2. Разность разностей с контрольными страницами вместо простого «до/после»

Сравнение «до/после» на одном сайте смешивает эффект мер с сезонностью, трендом и обновлениями алгоритма.
Контрольные страницы вычитают общие изменения. Синтетический сценарий это показывает: для H4 истинный эффект
равен нулю, «до/после» даёт интервал без нуля, а DiD нет (таблица абляции в отчёте).

Альтернатива: Bayesian structural time series (CausalImpact, Brodersen et al., 2015) для одной
временной ряда сайта. Её можно добавить как дополнительную проверку, если групп страниц не хватит.

## D3. Bootstrap по страницам

Дни одной страницы сильно зависимы; обычный bootstrap по дням дал бы слишком узкие интервалы (Bertrand,
Duflo & Mullainathan, 2004). Ресэмплирование целых страниц это учитывает. Ограничение: при 5 страницах
в группе интервалы приблизительные.

## D4. Бонферрони

Четыре проверяемые гипотезы. Консервативная поправка проста для объяснения на защите. В отчёте видны оба
интервала, 95 % и скорректированный.

## D5. Синтетический снимок для smoke и тестов

Без реальных данных нельзя проверить, что метод находит известный эффект. Генератор детерминирован
(seed 20260911); тест сравнивает его вывод с закоммиченным снимком, поэтому незаметная замена данных
невозможна. Заложены эффекты H1 = 28 %, H2 = 30 %, H3 = 20 п.п., H4 = 0.

## D6. Конфиденциальность

Реальные данные компании и PDF диспозиции (подписи, номер студента) не попадают в публичный репозиторий.
В git хранятся схема, способ получения и контрольные суммы.

## D7. Демонстрация: GitHub Pages через Actions

Сайт статический (HTML/CSS/JS без сборщика). Данные `site/data/demo_public.json` создаёт `release` в CI
из того же запуска, что и таблицы; в git они не хранятся. Поэтому сайт не может разойтись с кодом.
Публичное имя экспорта (`demo_public`) отличается от печатной версии (`thesis_print`).

## D8. Язык интерфейсов

Сайт и формулировки гипотез на словенском (язык диплома и комиссии), документация для команды на русском,
идентификаторы и код на английском.

## Команды воспроизведения

Из корня репозитория, в окружении с requirements.lock, с установленным пакетом (`python -m pip install --no-deps -e .`):

```powershell
python -m pytest -q --junitxml=reports/revision-junit.xml
python -m research smoke
python -m research verify --run-id <id-нового-запуска>
python thesis/tools/public_audit.py --url https://b0gdaan.github.io/artem_klevie_masini/ --out reports/public-audit-new
```

Последняя команда получает новый снимок: он может отличаться от исторического. Для воспроизведения исторических результатов используют сохранённый HTML, а не повторное скачивание изменяемой страницы.

## Короткие ответы для защиты

**Почему синтетика?** Реальных выгрузок и внедрений нет. Здесь исследуется правильность метода на контролируемом примере, а не эффект реального SEO.

**Что настоящее?** Снимок HTML публичной страницы. Он подтверждает только её технические характеристики на момент получения.

**Почему есть контрольная группа?** Чтобы отделить изменение обработанных страниц от общего изменения. Это помогает только при приемлемой сопоставимости групп.

**Что такое bootstrap?** Многократное повторное формирование выборки из имеющихся страниц для оценки неопределённости. Оно не создаёт новые независимые наблюдения.

**Что значит не определено?** Интервал допускает как значения выше исследуемого порога, так и ниже. Нельзя уверенно подтвердить или отвергнуть заявленный размер эффекта.

**Что доказывают 53 теста?** Проверенные свойства программы и расчётов. Они не доказывают качество SEO, отсутствие всех ошибок или причинность.

**Можно ли обещать рост на 27 %?** Нет. Это результат конкретной симуляции с заданными эффектами.

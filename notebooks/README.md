# Notebooks

Здесь будут тетради для объяснения и диагностики. Они только читают артефакты запуска и ничего не
пересчитывают для текста:

- `01_data_overview.ipynb`: покрытие данных GSC по страницам и дням, пропуски, сегменты;
- `02_parallel_trends.ipynb`: тренды обработанных и контрольных страниц в pre-периоде;
- `03_power.ipynb`: какой минимальный эффект заметен при текущем числе страниц и показов (до периода «после»).

Правило: в первой ячейке указывается `run_id`, и все файлы читаются из `runs/<run_id>/`.

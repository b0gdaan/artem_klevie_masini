# Презентация к защите (план)

10–12 слайдов, около 10 минут. Язык словенский. Графики берутся только из `releases/<run_id>/report/figures`.

1. **Naslov**: тема, автор, менторы, дата.
2. **Problem**: компании платят за рекламу и не используют органический поиск; доля Google в Словении (с источником).
3. **Raziskovalna vprašanja in hipoteze**: RV1–RV4, H1–H5 в уточнённой формулировке, пороги.
4. **Spletno mesto in zasnova**: группы страниц, контрольная группа, окна до/после (схема).
5. **Revizija**: число и типы ошибок до/после (`audit_issues.png`), связь с RV4.
6. **Ukrepi**: журнал мер с датами.
7. **Rezultati**: `effects.png`, по одному предложению на гипотезу.
8. **Časovna vrsta**: `timeseries.png` для самой ясной гипотезы.
9. **Ali je rezultat zanesljiv?**: placebo, абляция, core updates в периоде.
10. **Dostopnost (tema BTEC)**: H4, WCAG, EAA.
11. **Sklepi in praktična vrednost**: что делать компании, что бесплатно (RV2), сколько ждать (RV3).
12. **Omejitve in nadaljnje delo**.

Резервные слайды: как устроена воспроизводимость (manifest, verify), ответы на вопросы из
`docs/DISPOZICIJA_REVIEW.md`.

Речь (`govor.md`) пишется после реального запуска: числа из `claims.csv`.
